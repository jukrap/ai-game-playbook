# 현재 상태와 범위

> 상태: 소스에서 실행하는 초기 기반입니다. 공개 명령은 프로젝트를 변경하지 않으며, 모든 엔진 지원 등급은 `planned`이고 배포 패키지도 없습니다.

[English](status-and-scope.md) · [문서 안내](README.ko.md)

## 지금 되는 일

이 저장소는 비공개 pnpm 작업 공간과 `agpb` 실행 파일을 소스에서 빌드합니다. 현재 명령은 9개입니다.

| 명령군 | 현재 동작 |
| --- | --- |
| `init` | 파일을 쓰지 않고 고정된 프로젝트 내부 구성을 계획 |
| `doctor` | 런타임, 레지스트리, 프로젝트 상태, 관리 상태의 건전성 검사 |
| `project inspect` | 제한된 엔진 표식과 커밋된 프로젝트 프로필 읽기 |
| `pack list`, `pack doctor` | 설치된 팩의 식별 정보, 소유권, 변형, 복구 상태 검사 |
| `skill list`, `skill check` | 패키지 스킬 12개를 나열하고 고정 설치 대상 검사 |
| `engine status`, `engine capabilities` | Godot 프로젝트 정적 호환성과 예정 작업의 미충족 조건 보고 |

아홉 명령 모두 프로젝트 파일 쓰기, 엔진 실행, 에디터 제어, 네트워크 접근, 소프트웨어 설치를 하지 않습니다. 사람이 읽는 출력과 JSON 출력은 같은 검증 결과와 종료 분류를 사용합니다.

타입이 있는 계약과 검증된 단일 레지스트리가 있습니다. 프로젝트·프로세스 제한, 권한·워크플로 상태, 영수증·산출물, 관리형 팩 트랜잭션도 기반으로 구현했습니다. 비공개 초기화는 고정 제어 구성과 소유권 없는 공용 `.agents/skills` 상위 경로를 롤백·지속 증거와 함께 만들거나 유지할 수 있습니다. 패키지 스킬 12개는 파일 해시로 검증하는 하나의 실험적 팩에 묶었습니다. 비공개 팩 추가 수명주기는 정확한 설치 승인, 오래된 계획 재검사, 하나의 프로젝트 쓰기 차선, 비교 후 교체 소유권, 체크포인트, 영수증, 내용 주소형 종료 트랜잭션 증거, 롤백, 복구 차단선까지 포함합니다. 읽기 전용 MCP 실행부와 쓰기 없는 호스트 설정 계획기도 있습니다. 위 공개 명령에서 노출하지 않는 부분은 제품 기능이 아니라 기반 구현으로 봅니다.

내부 복구 종료는 새 복구 실행과 기존 팩 트랜잭션의 식별 정보를 분리합니다. 새 승인을 요구하고, 프로젝트 쓰기 차선 하나에서 트랜잭션을 다시 검사하며, 저널 종료·내용 주소형 종료 증거·`RunReceipt`·최종 워크플로 체크포인트가 모두 일치할 때만 성공을 반환합니다. 트랜잭션을 닫은 뒤 증거 저장에 실패하면 성공을 반환하지 않고, 나중에 상태를 맞출 수 있도록 시작된 체크포인트를 남깁니다. 해당 변경을 자동으로 다시 시도하지 않습니다.

## 아직 안 되는 일

설치하거나 배포할 수 있는 패키지는 없습니다. 다음 기능도 아직 제공하지 않습니다.

- 공개 프로젝트 초기화와 스킬 설치
- 공개 팩 추가·갱신·제거·복구·복구 종료
- Godot, Unity, Unreal 실엔진 브리지
- 에디터 연결, 씬·자산 변경, 게임 입력, 실행 화면 캡처
- 엔진 테스트, 실행 가능한 골든 프로젝트, 빌드·내보내기 실행
- 증거 목록·조회·내보내기와 출시 게시

내부 Godot 탐색·사전 검사 코드가 있다고 해서 지원 상태가 올라가지는 않습니다. 현재 격리 제공자 목록이 비어 있어 프로젝트 프로세스 승인은 안전하게 차단되며, 실엔진 지원도 성립하지 않습니다.

## 제품 범위

첫 완성 목표는 Windows x64용 오프라인 싱글플레이 3D 버티컬 슬라이스입니다. 이동, 카메라, 충돌, 수집물, HUD 개수 표시, 저장·불러오기, 승리 상태, 결정적 재생, 테스트, 실제 실행 화면 캡처, 로컬 빌드를 포함합니다.

Godot 어댑터를 먼저 만들고 Unity와 Unreal Engine을 이어서 구현합니다. 에디터가 필요 없는 검사는 Linux CI에서도 실행합니다. 실제 에디터를 확인해야 할 때는 Windows 실행기를 사용합니다.

웹 게임 프레임워크, 멀티플레이, 모바일, 콘솔, XR, macOS 검증, 데스크톱 대시보드, 엔진 자동 설치, 외부 3D·오디오 생성은 첫 알파 범위에서 제외합니다.

## 출시 단계의 의미

현재 버전은 `0.0.0`이며 알파 출시로 표현하면 안 됩니다. `0.1.0-alpha`는 Godot 회색 상자 프로젝트의 전체 흐름을 실행하고 증거까지 보존해야 붙일 수 있습니다. Unity와 Unreal은 각자 같은 흐름을 통과할 때까지 `planned`로 남습니다.

`1.0.0`은 세 엔진 모두 선언된 골든 프로젝트에서 `verified`에 도달하고, 설치 수명주기·롤백·권한·증거·행동 평가 계약이 안정화된 뒤에만 허용합니다.

현재 패키지 표시는 `UNLICENSED`입니다. 패키지를 배포하거나 외부 코드를 포함하기 전에 프로젝트 라이선스를 정해야 합니다.
